# FishScanner Aquarium

Основано на [david-svitov/fishscanner](https://github.com/david-svitov/fishscanner):
оригинальный алгоритм вырезания рыбки с фото (ArUco-метки + удаление фона)
переиспользован в веб-версии. Вместо десктопного OpenGL-окна — общий
аквариум в браузере (в том числе как PWA — можно поставить на телефон
прямо со страницы, без магазина приложений и без сборки).

## Состав проекта

```
docker-compose.yml      # запуск всего одним контейнером на порту 8015
backend/                # FastAPI-сервер + веб-страница аквариума (она же PWA)
  app/scanner.py         # вырезание рыбки с фото (адаптировано из engine/simplescanner.py)
  app/main.py            # REST API + WebSocket + отдача статики
  static/                # index.html + Canvas-анимация аквариума (app.js) + PWA-манифест
```

## Запуск сервера

```bash
docker compose up --build
```

Открыть в браузере: **http://localhost:8015**, либо на вашем адресе,
например `https://aquarium.example.com`, если пробросили порт 8015 через
обратный прокси (Nginx Proxy Manager, Caddy и т.п.).

Данные (рыбки, фоны) хранятся в volume, смонтированном в
`docker-compose.yml` в `./fish_data:/data/fish_storage` — переживают
пересборку и перезапуск контейнера.

## Установка как приложение на телефон (PWA)

Открыть сайт в браузере на телефоне → в меню браузера (⋮ в Chrome, «Поделиться»
в Safari) выбрать **«Добавить на экран «Домой»»** / **«Установить приложение»**.
На главном экране появится иконка, открывающая аквариум в полноэкранном режиме,
без адресной строки.

> Полноценный баннер «Установить приложение» (с кнопкой прямо на странице)
> появляется только на HTTPS — если сайт открыт по обычному `http://IP:8015`
> в локальной сети, кнопки не будет, но ручная установка через меню браузера
> всё равно работает. У вас уже есть HTTPS через `aquarium.zoltech.ru` —
> там кнопка установки должна появляться сама.

## Как рисовать и добавлять рыбок

Два варианта фотографирования — оба поддерживаются одним и тем же сервером:

1. **С распечатанным бланком (лучшее качество).** Распечатайте
   `backend/static/assets/fish_pattern.pdf` (это оригинальный шаблон с
   4 ArUco-метками по углам), нарисуйте рыбку внутри рамки и сфотографируйте
   целиком, включая все 4 метки — сервер выровняет перспективу и точно
   вырежет фон.
2. **Без бланка (быстрый вариант).** Просто сфотографируйте рисунок рыбки на
   светлом/белом листе бумаги — сервер вырежет светлый фон без выравнивания
   по меткам.

Кнопка «📷 Добавить рыбку» на странице аквариума открывает камеру телефона
напрямую (или выбор файла на компьютере). Новая рыбка появляется в реальном
времени у всех, кто в этот момент смотрит аквариум (через WebSocket).

## Удаление рыбок

- **На телефоне** — нажать и удерживать рыбку (долгое нажатие), появится
  подтверждение.
- **На компьютере** — щёлкнуть по рыбке правой кнопкой мыши.

Удаление сразу видно всем зрителям аквариума.

## Фон аквариума

Кнопка 🎨 в правом верхнем углу открывает панель:

- **Галерея фонов** — встроенный «Риф» плюс любые загруженные свои картинки.
  Можно переключаться между ними в один клик, а ненужные — удалять (крестик
  на превью).
- **«+ Свой фон»** — загрузить новую картинку в галерею.
- **Освещение** — фильтры Обычное / День / Закат / Ночь, которые накладываются
  поверх ЛЮБОГО выбранного фона (и рифа, и своих картинок).

Фон и выбранный фильтр общие для всех зрителей и сохраняются между
перезапусками контейнера.

## Технические детали

- **Backend:** FastAPI + OpenCV (алгоритм вырезания фона 1:1 из оригинала)
  + WebSocket для live-обновлений (новые/удалённые рыбки, смена фона).
- **Frontend:** обычный HTML5 Canvas (без WebGL) — логика движения рыбок
  (всплытие → плавание по всему экрану → отражение от краёв → пузырьки)
  портирована из `ocean/drawingfish.py` оригинального проекта. Удаление —
  через попадание в bounding box рыбки по клику/долгому нажатию.
- **PWA:** `manifest.json` + `service-worker.js` кэширует только статическую
  оболочку (HTML/CSS/JS/иконки) — API, WebSocket и загруженные картинки
  рыбок/фонов всегда идут напрямую на сервер, не кэшируются.
- **Хранение:** PNG-файлы рыбок и фонов + JSON-индексы в volume `fish_data`.
